# LoauTech - Sistema de Gestión de Elementos

## Introducción

**LoauTech** es un sistema de información desarrollado para gestionar y controlar el registro de entrada y salida de elementos y equipos en el **CDATH (Centro de Desarrollo Agroempresarial y Turistico Del Huila)**. El proyecto está construido sobre una arquitectura Modelo-Vista-Controlador (MVC) utilizando PHP puro.

---

## Requisitos Previos

Antes de comenzar, asegúrate de tener instalado el siguiente software en tu sistema:

-   **Servidor web local:** [XAMPP](https://www.apachefriends.org/es/index.html) 
-   **PHP:** Versión 8 o superior.
-   **Base de datos:** MySQL - MariaDB.
-   **Git:** Para clonar el repositorio.
